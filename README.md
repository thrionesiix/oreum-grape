# 🍇 포도알 공부 인증

카카오톡 오픈채팅방에 올라온 공부 인증 사진을 모아 학생별 '포도알'을 채우고,
한 송이를 다 채우면 보상을 주는 프로그램입니다.

카카오 오픈채팅은 공식 API로 메시지를 읽을 수 없어서,
**대화 내용 내보내기**로 받은 txt 파일을 웹페이지에 끌어다 놓으면 파싱해서 집계합니다.

## 페이지 두 장

| 주소 | 누가 | 하는 일 |
|---|---|---|
| `index.html` | 선생님 | 대화 파일 집계 · 명단 관리 · 포도밭 · 시트로 올리기 |
| `student.html` | 학생 | 자기 포도송이 · 인증한 날 · 전체 랭킹 (조회만) |

## 어떻게 집계하나

- **사진·동영상 메시지만** 인증으로 칩니다 (설정에서 글 인증도 켤 수 있음).
- **하루 최대 1알.** 같은 날 여러 장 올려도 1알입니다.
- **새벽 3시 이전 메시지는 전날 공부로** 칩니다. 늦게까지 공부한 학생이 손해 보지 않게요. (기준 시각 변경 가능)
- 같은 파일을 다시 올려도 **중복으로 쌓이지 않습니다.**
- 카톡 내보내기 3가지 형식(안드로이드 / 아이폰·PC / PC CSV)을 모두 읽습니다.

## 저장 구조

- **1차 저장소는 선생님 브라우저의 localStorage.** 기록이 날아가지 않게 여기에 먼저 저장합니다.
- **구글 시트는 사본.** 학생이 자기 현황을 보려면 필요합니다.
  네트워크가 실패해도 집계는 브라우저에 그대로 남고, 실패는 화면에 분명히 알립니다.
- 쓰기(`doPost`)는 선생님만 아는 키를 요구하고, 조회(`doGet`)는 열려 있습니다.
  학생 링크에는 키가 들어가지 않습니다.

## 백엔드 설치

`AppsScript.gs` 파일 맨 위 주석에 배포 방법이 단계별로 적혀 있습니다.
요약하면 — 구글 스프레드시트 → 확장 프로그램 → Apps Script → 코드 붙여넣기 →
`WRITE_KEY` 바꾸기 → 배포(웹 앱, 액세스 권한 **모든 사용자**) → 나온 URL을
선생님 페이지 설정 탭에 입력.

시트 두 장(`students`, `records`)은 첫 요청 때 자동으로 생깁니다.

## 쓰는 순서

1. 오픈채팅방에서 대화 내용을 txt로 내보냅니다.
2. `index.html`에 파일을 끌어다 놓습니다.
3. 모르는 닉네임이 있으면 누구인지 지정합니다 (한 번 지정하면 기억합니다).
4. **포도밭에 반영하기** → **설정 → ⬆️ 시트로 올리기**
5. 학생은 `student.html`에서 자기 이름을 눌러 확인합니다.

의존성 없는 단일 파일 3개입니다. 빌드 과정이 없습니다.
